# Contributing to CodePark

Thanks for contributing. Please open an issue before starting substantial work so the approach can be discussed.

## Development

Use Node.js 18.17 or newer, then run:

```bash
node ./bin/check-syntax.js
node --test
```

Keep changes focused, include tests for behavior changes, and update the README or changelog when user-facing behavior changes.

## Pull requests

- Explain the problem and solution clearly.
- Keep the working tree free of generated files and secrets.
- Run the syntax and test commands above before requesting review.
